## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动Web界面

```bash
cd web
python main.py
```

访问 http://localhost:8000

### 3. 启动桌面宠物

```bash
python desktop_pet.py
```
